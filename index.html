Todo-приложение
Описание проекта:

Интерактивное приложение для управления задачами. Позволяет добавлять, редактировать, удалять и отмечать задачи как выполненные. Данные сохраняются в локальном хранилище браузера. Реализована фильтрация задач по статусу и поиск по задачам.

Технологии: JavaScript, LocalStorage, CSS3

Особенности: Сохранение данных в браузере, фильтрация задач, валидация ввода

Интернет-магазин
Описание проекта:

Полнофункциональный интернет-магазин с каталогом товаров, корзиной покупок и системой оформления заказов. Реализована фильтрация товаров по категориям, поиск по названию и цене. Есть возможность оставлять отзывы и рейтинги для товаров.

Технологии: React, React Router, Context API, Firebase

Особенности: Аутентификация пользователей, работа с API, пагинация
